# Petr Lavrenovs Portfolio

Static portfolio site prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `dustypetrol.github.io`.
2. Add `index.html`, `styles.css`, `.gitignore`, `README.md`, and the `assets/` folder.
3. Do not publish the raw PPTX files or the `PicsFromHackathon/` source folder.
4. Push to the `main` branch.
5. In GitHub, open Settings > Pages and publish from the `main` branch root.

The site is plain HTML and CSS, so it does not need a build step.
